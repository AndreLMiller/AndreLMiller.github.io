<h2>What Is a UI Framework and Why Does It Even Matter</h2>
<p>   A UI framework is like a construction worker's tool belt, to complete a job he needs to use the tools in his belt to complete his job quickly and efficiently. For some jobs he may not need to use some tools, but other times he may need to use all of his tools depending on how complicated the job is.  As a construction worker needs his belt so does a devloper need UI frameworks.  That was a bit of a reach but basically all I mean is that UI frameworks are a collection of tools or templates that help a developer create interfaces or websites for the web.  They help to speed up the process of building websites and makes their work a lot more consistent as well.  Learning this can take a lot of time since there are so many tools, it's like learning a completely learning a new programming language, so why use it?  The answer is time,  learning the language may take time, but it could also save a lot of time as well.</p>



<h2>Bootstrap 5</h2>
<img src="../img/bootstrapIcon.jpg" width=150px> 
<p>  In my class we are using bootstrap 5 for our UI framework.  Bootstrap 5 is a very popular front-end framework taht is used for developing responsive layouts and has many different tools and components that help with the speed oof building yoour web designs.  Some of these tools consist of buttons, icons, navbars, and also utilizes grids, rows and columns to help organize and create layouts for your websites.</p>
